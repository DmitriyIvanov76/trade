# Электронная торговля


### Данный проект содержит:

1) class Product
* название
* описание 
* цена 
* количество в наличии
* 

2) class Category
* название
* описание 
* список товаров категории
* количество категорий
* количество товаров 

3) Реализованы дочерние классы для добавления Смартфонов и газонной травы 

4) Реализован функционал чтения информации из JSON файла и ее обработки для дальнейшего использования

#### Добавление продуктов только с помощью класса Product, или унаследованных от него классов
#### Работа классов проверена с помощью pytest
