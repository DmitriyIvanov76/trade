# Электронная торговля


### Данный проект содержит:

1) class Product
* название
* описание 
* цена 
* количество в наличии

2) class Category
* название
* описание 
* список товаров категории
* количество категорий
* количество товаров

3) class BaseProduct
* родительский класс для класса продуктов

4) class PrintMixin
* печатает в консоль информацию о том, от какого класса и с какими параметрами был создан объект
 
5) Реализованы дочерние классы для добавления Смартфонов и газонной травы 

6) Реализован функционал чтения информации из JSON файла и ее обработки для дальнейшего использования

#### Добавление продуктов только с помощью класса Product, или унаследованных от него классов
#### Работа классов проверена с помощью pytest
